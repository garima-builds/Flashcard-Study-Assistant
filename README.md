# 🧠 Flashcard Study Assistant

A simple interactive web application that helps students revise important concepts using digital flashcards.

## 📌 About the Project

Flashcard Study Assistant provides a collection of study questions and answers in an interactive flashcard format.

Users can reveal answers, move between flashcards, shuffle the cards, track their score, and view their final performance after completing the study session.

## ✨ Features

- 🃏 Interactive question-and-answer flashcards
- 👁️ Show Answer option
- ⬅️ Previous and Next navigation
- 🔀 Shuffle flashcards
- ✅ Track correct answers
- ❌ Track incorrect answers
- 📊 Automatic score calculation
- 📈 Progress indicator
- 🎉 Final score and performance message
- 🔄 Restart study session
- 📱 Responsive design

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Right-click on `index.html`.
5. Select **Open with Live Server**.

You can also open `index.html` directly in a web browser.

## 🧠 How It Works

The flashcards are stored as JavaScript objects containing a question and its answer.

The application allows the user to:

1. Read a question.
2. Reveal the answer.
3. Mark whether they know the answer.
4. Move to the next flashcard.
5. Track their score.
6. Complete the study session and view their final performance.

The shuffle feature randomly changes the order of the flashcards.

## 📊 Scoring

The application calculates the final score based on the number of questions marked as correct.

- **80% or above:** Excellent performance
- **50%–79%:** Good effort, but more revision is recommended
- **Below 50%:** More practice and revision are recommended
